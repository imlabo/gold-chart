データ元と見方

ゴールド：Binance PAXG は登録不要で15秒ごとに自動更新します（金1トロイオンス裏付けのトークンで、値動きは金スポットとほぼ同じ。数ドルのずれと土日の値動きあり）。Twelve Data XAU/USD は金スポットそのもので、twelvedata.com の無料APIキーが必要です（1日800回・1分8回の枠に収まるよう、表示中の足を3分ごと、他の足を1時間ごとに更新）。

日経225先物・NASDAQ100先物・ドル円・金先物：ブラウザから直接は取れないため、このサイトの GitHub Actions が5分ごとに Yahoo Finance から四本値を取得して公開しています（日経225先物は CME 円建て NIY、NASDAQ は NQ、金先物は COMEX GC）。表示は約5分遅れで、1分足は直近7日分、5分足は7日、15分足は30日、1時間足は120日、日足は5年分から直近1,000本。4時間足は1時間足から合成します。ドル円は Twelve Data の無料キーでも取れます。

時刻はお使いの端末の時刻（ベトナムならUTC+7）で表示します。日足・三日足・九週足の区切りはデータ元に合わせてUTC 0時です。各時間足で直近1,000本を取得し、210本移動平均と雲もその中で計算します。

支持線・抵抗線の主役はお椀の水平線です。日足・4時間・1時間で、過去のトレンドの起点（戻り売り・押し目買いの起点）から大きく離れたあと価格が全戻ししてきた価格を探し、深く・大きく・初回の戻りほど強くします。1分足・5分足の小さなお椀は使いません。二重線で描き、○がその起点です。

水平線の近くに移動平均線（特に20と210、各時間足）があると大きく加点し、別の時間足のMAが2本以上重なればさらに加点します（右端の◆印）。ほかに三尊・逆三尊のネックライン候補、はっきりした一波の半値戻し、4時間足以上の大きなローソク足の四本値、進行中の日足の始値（陰線にさせまいの攻防）、基準線・先行スパン2の横ばい、$50・$100の節目を集め、近い価格をまとめて点数化します。その後に何度も抜けた価格は減点、直前にスラストがある側の水平線は警戒表示です。現在値の上下それぞれ最大4本を、強い順に濃く太く描きます。

1分足（なければ5分足）では、水平線に触れたときの反応を印で示します。★＝直近にない長さの足・ヒゲ（反発のシンボル）、◆＝接触後の20MA割れ（抜け）確定、✕＝高値安値更新フェイク。欄外には最寄りの水平線までの距離と、20MAから大きく乖離して接触した型①／水平線と20MAにサンドイッチされた型②の判定を出します。
