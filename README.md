# GOLD 一目チャート

金（XAU/USD）の 1分・5分・15分・1時間・4時間・日足を、移動平均 5 / 20 / 75 / 210 と一目均衡表（波動・値幅観測・時間論・相場水準・三日足・九週足）で読む独自チャートです。TradingView は使っていません。価格は無料APIから自動で取り込みます。

## データ元（どちらも無料）

| データ元 | 登録 | 銘柄 | 更新間隔 |
|---|---|---|---|
| Binance PAXG/USDT（初期設定） | 不要 | 金1トロイオンス裏付けのトークン。値動きは金スポットとほぼ同じ（数ドルの差・土日も動く） | 表示中の足は15秒ごと、他の足は5分ごと |
| Twelve Data XAU/USD | twelvedata.com で無料登録してAPIキーを取得 | 金スポットそのもの | 表示中の足は3分ごと、他の足は1時間ごと（無料枠1日800回に収まる設定） |

画面上部の「データ元」で切り替えます。APIキーはブラウザ内にだけ保存されます。

## 使い方

### パソコンで使う
`index.html` をダブルクリックしてブラウザで開くだけで動きます。

### スマホからも見たい（GitHub Pages・無料）
1. GitHub で新しいリポジトリを作り、`index.html` と `.nojekyll` を置く
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

## 画面の見方

- **チャート**：ローソク足、移動平均4本、転換線・基準線・雲（26本先）・遅行スパン（26本前）、三役好転／逆転、雲のねじれ、山谷のジグザグ（A・B・C）、N・V・E・NT計算値、基本数値（9・17・26・33・42・65・76・129・172本目）と対等数値の縦線
- **時間足ごとの判定**：MA配列（パーフェクトオーダー）、雲、転換線と基準線、遅行スパン、三役、基準線の値と向き、総合。1時間・4時間・日足がそろうと「押し目買い目線／戻り売り目線」
- **支持線・抵抗線**：主役は「お椀の水平線」（日足・4時間・1時間で、過去のトレンドの起点から大きく離れたあと全戻ししてきた価格。深く・大きく・初回の戻りほど強い。二重線＋起点の○）。水平線の近くに各時間足の移動平均線（特に20・210）があれば大きく加点し、別の時間足のMAが重なればさらに加点（右端の◆）。ほかにネックライン候補、半値戻し、4時間足以上の大きなローソク足の四本値、進行中の日足の始値、基準線・先行スパン2の横ばい、$50・$100の節目。何度も抜けた価格は減点、直前にスラストがある側は警戒表示。現在値の上下それぞれ最大4本を効きやすい順に濃く太く描き、根拠を一覧表示
- **1分足の反応チェック**：水平線に触れたときの反応を印で表示。★＝直近にない長さの足・ヒゲ、◆＝接触後の20MA割れ（抜け）確定、✕＝高値安値更新フェイク。最寄りの水平線までの距離、20MAからの乖離、型①（大きく乖離して接触）／型②（水平線と20MAのサンドイッチ）の判定
- **三日足・九週足**：日足から合成。上げ足・下げ足・包み足・はらみ足と、その足の半値に対する位置。起点はずらして合わせられます
- **相場水準**：9〜76本の各期間の半値と現在値の上下

分析用のツールで、売買を勧めるものではありません。
